# 0x0B. C - More malloc, free

This project covers more dynamic memory allocation in C using `malloc` and `free`.

## Tasks

* **0-malloc_checked.c**: allocates memory using malloc and exits with status 98 on failure.
* **1-string_nconcat.c**: concatenates two strings using at most n bytes of the second.
* **2-calloc.c**: allocates memory for an array using malloc and sets it to zero.
