# 0x0D. C - Structures, typedef

This project covers structures and `typedef` in C.

## Tasks

* **dog.h**: defines a new type `struct dog` with `name`, `age` and `owner`.
* **1-init_dog.c**: initializes a variable of type struct dog.
* **2-print_dog.c**: prints a struct dog.
* **dog.h**: defines the new type dog_t as a new name for struct dog.
* **4-new_dog.c**: creates a new dog.
